Most enterprises are stuck in the same place: the AI pilot works, and then it dies on the way to production. Different verticals, same wall. My day job is helping the largest organizations across APJC get infrastructure, data, and governance to the point where intelligence actually ships — and stays shipped.

I write about that gap at [deepakwaghmare.com](https://deepakwaghmare.com): where AI economics, workload sovereignty, and enterprise resilience meet the physics of real data centers.

This GitHub is the workbench behind the writing — the code, benchmarks, and reference builds I use to pressure-test an argument before I make it in public. I'm an executive who still believes you don't understand a claim until you've run it.

### What lives here

- **[vexpose-labs](https://github.com/waghmaredb/vexpose-labs)** — the working code behind [vExpose](https://www.vexpose.blog) posts: benchmarks, experiments, and the scripts I use to check my own numbers before publishing.
- **Infrastructure-as-code reference builds** — Kubernetes, OpenShift on bare metal, and storage automation from years spent closer to the metal. Kept public because someone always needs a working example.
